Trên Máy Tính (PC)

★ Khuyên Dùng
  1. Mở Discord Web trên trình duyệt.
  2. Nhấn F12 hoặc Ctrl+Shift+I để mở công cụ DevTools.
  3. Chuyển sang tab Network (Mạng).
  4. Gõ /api/ vào ô Filter (Lọc).
  5. Click vào một request bất kỳ hiện ra (VD: science).
  6. Kéo xuống Request Headers, tìm và copy đoạn mã tại dòng Authorization.

Trên Điện Thoại

  1. Tải trình duyệt Kiwi Browser (Android) hoặc Safari (iOS).
  2. Truy cập Discord Web, đăng nhập và bật chế độ "Trang web cho Máy tính".
  3. Mở Developer Tools trong menu cài đặt của trình duyệt.
  4. Thực hiện các bước tìm Token trong tab Network giống trên PC.
